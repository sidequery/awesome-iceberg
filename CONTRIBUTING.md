# Contributing

Thanks for your interest in contributing to this awesome list!

## Guidelines

- Search previous suggestions before making a new one to avoid duplicates
- Make an individual pull request for each suggestion
- Use the following format: `[Resource Name](link) - Description.`
- Descriptions should be clear, concise, and non-promotional
- Descriptions should follow the link, on the same line
- New categories or improvements to existing categories are welcome
- Check your spelling and grammar
- The pull request should have a useful title

## Quality Standards

- Resources should be actively maintained or still relevant
- Links should point to original sources when possible
- Avoid links that require payment or registration when free alternatives exist

## How to Contribute

1. Fork the repository
2. Add your suggestion to the appropriate category
3. Commit: `git commit -m "Add resource-name"`
4. Push and open a Pull Request

Thank you for your contribution!
